# BadHashPy

## Purpose

BadHashPy provides a drag-and-drop interface in which you can drop a file and immediately receive MD5, SHA-1 and SHA-256 hashes.

## Structure

There are two version of this applet:

** Version 1:** Builds a basic interface with drag-and-drop functionality.
** Version 2:** Uses the dnd-toolkit module from another repo and provides the same functionality using less code to build a cleaner interface.
